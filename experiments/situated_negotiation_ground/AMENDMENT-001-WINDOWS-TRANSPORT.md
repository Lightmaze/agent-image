# Formal infrastructure amendment 001 — Windows consolidation transport

Recorded after the formal run had completed 192 before-evaluation calls and 16
trained-arm episodes, before any formal score or action distribution was
inspected.

The first 16-episode consolidation did not start a provider call and produced
no Hermes usage ledger. Its prompt was 30,751 UTF-8 bytes before executable,
path, model, provider, and resume arguments were added. The 8-episode pilot did
not expose this Windows command-line boundary.

The transport representation is amended to send, for every one of the 16
episodes, the scenario id, cohort, public bounds, private authority, action,
offer, revealed seller floor, ideal action/offer, score, regret, and complete
reflection evidence. Full decisions, seller-facing messages, rationales,
consequences, model usage, and raw response digests remain unchanged in the
authoritative private episode ledger. No episode is removed, replaced, or
resampled. Thresholds, seeds, policies, arms, counts, and statistical analysis
are unchanged.

An acceptance test now requires a 16-episode consolidation with a current
playbook to remain below 20,000 UTF-8 bytes and to include all 16 scenario ids
and seller-floor observations.
