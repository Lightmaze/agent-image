# Open Agent Image Protocol v0.1.0-rc.1

Date: 2026-08-26

Status: **local release candidate; not yet publicly published**

This candidate is the first version organized around a developed Agent that a
new operator can actually restore and use. The release bundle contains the
protocol CLI, its source distribution, and a public-safe Hermes Agent Image:

`procurement-negotiator-v1.aimg`

The image was derived from 128 episodes of synthetic procurement practice. Its
file SHA-256 is
`9cd98ace2471203e93f07d3877a477b288ed08088df14a4ac02f0a3e36cd9206`;
its Agent Image digest is
`sha256:8a258bc82ba8b161a107a4cf970c51e1f19228dcc78c8696e0bf13a699e257b2`.

## What the operator gets

After installing the wheel, the operator can verify and inspect the artifact,
restore it into an absent Hermes `0.20.5` profile, and immediately use the
restored Agent. The [README hero path](../../README.md#try-the-developed-agent)
and [focused example](../../examples/procurement-negotiator/README.md) contain
the exact PowerShell and Bash commands.

The public-restored Agent scored `1.000000` on 24 new synthetic decisions. The
same `deepseek-v4-flash` model with the same parameters and no situated practice
scored `0.481521`. There were zero reservation-price leaks. This is bounded
same-harness evidence, not a real-world procurement or P3 claim.
The separate [operator-path smoke](../evidence/public-hero-operator-path-2026-08-26.md)
then installed the bundle wheel, fresh-restored the copied asset, and obtained
the expected `counter 260` response on the README scenario.

## Public boundary

The public derivative contains identity, its Agent-authored playbook, synthetic
practice and consolidation history, development/evaluation provenance, and a
minimal typed Hermes native snapshot. Runtime caches, logs, `state.db`, locks,
credentials, and nonessential private state were removed through an explicit
whitelist. All seven included layers are public; unknown future state remains
private by default.

The planned online private-parent control was removed before any provider call.
Permission to spend model credits does not authorize sending private Agent state
to that provider. Prior private Gate E evidence remains digest-bound lineage
support and is not mixed into the public comparison scores.

## Release boundary

The local candidate is complete only after the bundle installs in a clean
environment and the hero path passes against the copied release assets. Public
repository creation, remote configuration, push, release creation, asset
upload, and tag publication require explicit authorization. Until a real asset
URL exists, the Registry correctly keeps the public-safe hero at a
`withheld://local-release-candidate/...` locator.
